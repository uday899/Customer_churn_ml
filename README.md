📉 Customer Churn Prediction

A Machine Learning project that predicts whether a customer is likely to churn or stay based on customer behavior, subscription, payment, and engagement data.

🎯 Objective

Identify customers at risk of leaving and understand the key factors influencing churn.

🛠️ Technologies
Python
Pandas & NumPy
Scikit-learn
Random Forest & XGBoost
Joblib
Streamlit
🤖 ML Workflow

Data Preprocessing → EDA → Model Training → Hyperparameter Tuning → 5-Fold Cross Validation → Evaluation → Deployment

🏆 Final Model

Tuned Random Forest Classifier

Key metrics used:

Accuracy
Precision
Recall
F1-Score
🚀 Deployment

The trained model is deployed using Streamlit to provide real-time churn predictions through a web interface.

🔮 Future Improvements
SHAP-based explainability
Customer risk segmentation
Automated model retraining
Cloud deployment
